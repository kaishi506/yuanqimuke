# 📖 项目介绍
元启慕课教育平台是一个在线的非学历职业技能培训平台，核心业务是以售卖各种技能培训的在线课程，并提供丰富的学习辅助功能、交互功能，以提升用户学习时的氛围感和学习的积极性
# 🛠 技术栈
Springboot、SpringCloud、nacos、nginx、MySQL、Redis、seata、RabbitMQ、xxl-job、ES

学生端：其核心业务主体就是学员，所有业务围绕着学员的展开
管理端：其核心业务主体包括老师、管理员、其他员工，核心业务围绕着老师展开
